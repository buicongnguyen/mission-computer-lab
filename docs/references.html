Upstream guides used for the integration

  • PX4 ROS 2 user guide (v1.16): client/agent architecture, message alignment and companion setup.
  • PX4 ROS 2 offboard control example (v1.16): the setpoint and proof-of-life pattern the mission adapter follows.
  • PX4 offboard mode (v1.16): entry requirements and loss behavior.
  • PX4 uXRCE-DDS bridge (v1.16): versioned topics such as vehicle_status_v1.
  • PX4 Gazebo simulation (v1.16): standalone Gazebo mode and model/world selection.
  • ROS 2 quality of service: best-effort sensor subscriptions and endpoint compatibility.
  • PX4 multi-vehicle simulation with Gazebo (v1.16): instance numbers, model names and DDS namespaces for the fleet.
  • ROS 2 clock and time design: use_sim_time and the /clock topic that keep every adapter on simulation time.
  • Gazebo system references: CameraVideoRecorder for the recorded videos, VelocityControl and OdometryPublisher for the carrier.

Guardian design background

  • ASTM F3442/F3442M-23, detect and avoid system performance requirements: the standard framing for keeping an unmanned aircraft clear of other traffic; the guardians' keep-clear logic is a simplified, simulation-only relative of it.
  • PX4 EKF2 tuning guide (v1.16): the GNSS quality checks (EKF2_GPS_CHECK, EKF2_REQ_HDRIFT) behind the moving-deck finding, and the aircraft-side view of navigation integrity that the station's spoofing cross-check complements.
